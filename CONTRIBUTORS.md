# openQ4 contributors

- **[themuffinator](https://github.com/themuffinator)** — project author and maintainer, DarkMatter Productions.
- **[Emile Belanger (emileb)](https://github.com/emileb)** — original Android platform port and SigmaTouch bridge; OpenGL ES 3.0 renderer and specialized shader variants; ETC2/EAC texture compression; mobile loading, cache, memory and audio improvements. His [Android](https://github.com/emileb/openQ4/tree/android) and [GLES shader-variants](https://github.com/emileb/openQ4/tree/gles-shader-variants) branches are the source of this contribution, adapted to current official openQ4. See the [integration record](docs/dev/android-gles-integration.md) for exact revisions and adaptations.
- **[danperisse-hue](https://github.com/danperisse-hue)** — faster level loads through the openPR06 port: reused PK4 read handles, zlib-ng PK4 inflate and CRC-32, level-load caches hashed with SHA instructions and written off the load thread, the modern GL shader library built at one GLSL tier, and small Ogg sounds inflated once. Ported from openPR06 pull requests #44-#51 in openQ4 47726228a, ef9e81829, 9afcf0e46 and f419ec332.
- **[Ronald Rivest and RSA Data Security, Inc.](https://www.rfc-editor.org/rfc/rfc1320)** — the native and Android PK4 compatibility checksums are derived from the RSA Data Security, Inc. MD4 Message-Digest Algorithm. Original notices are retained in the implementations and [MD4 notice](LICENSES/MD4.txt).

The [README credits](README.md#credits) acknowledge the upstream projects, source authors, libraries and testing contributions on which openQ4 depends. Original source notices remain in their files.
