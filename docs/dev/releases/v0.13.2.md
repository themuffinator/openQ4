# openQ4 0.13.2

Released 14 September 2026. **Superseded by [0.14.1](v0.14.1.md), the latest available release.**
The later 0.14.0 release (`v0.14.000`) was withdrawn because it was broken.
See [release status and matching guides](../../user/release-status.md).

## Highlights

- Fixes a campaign-save failure involving animated interface state.
- Fixes memory corruption triggered by a second mod in the Mods menu.
- Keeps multiplayer chat aligned with the left edge of the screen.
- Restores AAS navigation compilation in the engine for mapping work.

## Upgrade Notes

- Install the complete 0.13.2 package, including its matching engine, renderer
  and SP/MP modules and bundled `baseoq4` content. Original Quake 4 assets are
  still required; original proprietary game-DLL mods are not supported.
- OpenGL is the recommended default. Vulkan is experimental in this release
  on every platform. Later Windows Vulkan qualification applies to development
  builds, not retroactively to 0.13.2.
- If returning from withdrawn 0.14.0, back up your saves and settings and use a
  separate, complete 0.13.2 installation. 0.13.2 writes format 3 saves and cannot
  read format 4 saves from the withdrawn or newer development builds.
- Retail Quake 4 1.4.2 multiplayer is incompatible with openQ4 0.13.2. Use
  matching openQ4 clients and servers; an older documentation claim that retail
  clients could join was incorrect.
- Linux ARM64 remains a preview; Windows ARM64 is experimental. There is no
  Android APK in the 0.13.2 release assets.
- The experimental macOS packages target Apple Silicon/arm64. Intel Mac and
  universal2 packages are not published, and Rosetta is not supported. Downloads
  are unsigned OpenGL/Metal bridge archives. The Metal variant is a
  Metal bridge around the OpenGL renderer, not a native Metal renderer;
  `platform_backend=native` is comparison-only diagnostic infrastructure, not a release backend.
  Qualification is tracked in [docs/dev/macos-signoff-evidence.md](../macos-signoff-evidence.md);
  later development evidence does not qualify these historical packages.

## Change Log

- Updated the bundled SDL3, OpenAL Soft and Vulkan dependencies.
- Improved multiplayer validation so it rejects stale staged packages and
  automated headless runs do not take control of the user's mouse.
- Corrected build, CI and source-provenance handling.
