# openQ4 0.14.000 — withdrawn

> **Withdrawn release:** 0.14.0 (`v0.14.000`) was released and then taken down
> because it was broken. **[0.14.1](v0.14.1.md) replaces it and is the latest available release.** These notes
> are retained as history, not installation advice or an announcement of an
> available download. See [release status and rollback guidance](../../user/release-status.md).

The original release notes follow. Their defaults, features and upgrade advice
describe that withdrawn build and must not be attributed to 0.13.2.

These notes describe the tagged 0.14.000 release, which defaults to the classic
interface (`ui_retained 0`). Later source builds restored the modern default
(`ui_retained 1`). See [Modern and Classic Screens](https://github.com/themuffinator/openQ4/blob/main/docs/user/client-settings.md#modern-and-classic-screens)
for current behavior and saved preferences.

## Highlights

- **Legacy UI is the default again.** The new UI is disabled by default because
  its performance overhead remains too high compared with the legacy interface.
  It is still available as an experimental opt-in; recent optimizations have
  reduced its cost, but have not made that cost negligible.
- **Android APK included.** An experimental, release-signed ARM64 build brings
  the Android/GLES port to the downloads, with matching single-player and
  multiplayer modules. Credit goes to [Emile Belanger (emileb)](https://github.com/emileb)
  for the original Android port and GLES renderer.
- **More faithful sound and effects.** Room reverb follows the original maps,
  radio and positional sound levels are closer to retail, and explosions and
  machinery shake the camera at their intended strength. Particle effects,
  monster impact sounds and looping audio after loading saves are improved.
- **Smarter multiplayer bots.** Bots choose safer routes, check jump landings
  and hazardous drops, recover from blocked paths, hear nearby combat and
  respond to team orders. Navigation and decision-making use less CPU time.
- **Campaign improvements.** Quake 4 and The Awakening have separate campaign
  saves and settings. Awakening gains fixes for frozen enemies, cockpit weapon
  targeting, vehicles and its opening dropship scene. The expansion remains
  unfinished alpha content and requires separately installed assets.
- **Renderer improvements.** Windows Vulkan support, outdoor shadows, temporal
  anti-aliasing at reduced render scales and physically based materials for
  mods receive extensive fixes. OpenGL remains the default renderer.

## Upgrade Notes

- **Existing UI preferences are preserved.** Enter `seta ui_retained 0` in
  the console to select classic, or `seta ui_retained 1` to try the modern UI.
  The choice is saved. An explicit `+set ui_retained` launch option overrides
  it on startup; remove or change a conflicting option. The development launch
  configurations explicitly select the modern UI except for the Stock UI entries.
- Replace the complete package, including the engine, renderer modules, both
  SP/MP game modules and bundled `baseoq4` data. Mixing modules from earlier
  builds is unsupported. Quake 4's original game assets are still required.
- New campaign saves use format 4 to preserve frozen enemies, Retch buffs and
  animation speeds. Supported format 3 saves still load on the same platform.
  Keep your old save slots if you plan to return to an older build: older
  versions cannot read the new format 4 saves.
- Restart Awakening's opening map after updating its scene scripts; an older
  save from that scene may need a fresh map start. See the
  [campaign guide](https://github.com/themuffinator/openQ4/blob/v0.14.000/docs/user/campaigns.md) for installing expansion assets.
- Existing key bindings are preserved. Bind **Quick Chat** in Settings >
  Controls > Weapons to use it with an existing configuration; new profiles
  use V or D-pad Down.
- Reselect **Quality** or **Ultra** to apply their shadow-map settings.
  Temporal anti-aliasing now defaults to automatic below native resolution;
  use `r_temporalAA 0` to keep the plain upscale. PBR materials are enabled by
  default for content that supplies them; use `r_pbrMaterials 0` to disable
  them. Stock Quake 4 assets do not contain PBR materials.
- Audio settings now follow the device's speaker layout by default, and room
  reverb stays enabled in performance presets. Existing profiles receive the
  documented audio and renderer default migrations. See the
  [gameplay settings](https://github.com/themuffinator/openQ4/blob/v0.14.000/docs/user/gameplay-settings.md) and
  [display settings](https://github.com/themuffinator/openQ4/blob/v0.14.000/docs/user/display-settings.md) guides.
- SDK-derived game code retains its original SDK EULA; the engine retains its
  GPL terms. The package includes the component licensing notices.
- Android requires Android 7.0/API 24 or newer, an ARM64 device with OpenGL ES
  3.0, and your own Quake 4 data. Copy your retail `q4base` contents to
  `/sdcard/Android/data/com.darkmatter.openq4/files/q4base/`. A gamepad or
  keyboard/mouse is needed for full gameplay; the standalone APK has no full
  touch gameplay overlay. Allow space for the APK, extracted overlays and
  retail data. See the [Android guide](https://github.com/themuffinator/openQ4/blob/v0.14.000/mobile/android/README.md).
- The Android APK uses a persistent release certificate for future updates.
  An earlier locally built debug APK has a different signature: back up its
  private saves before uninstalling it to install this release. Dependency
  sources are available beside the APK for rebuilding with modified libraries.
- **Signed macOS builds are available from [Mac Source Ports](https://www.macsourceports.com/game/quake4), courtesy of Schnapple.** These signed and notarized Universal 2 builds support Apple Silicon and Intel Macs on macOS 11 or later; see the download page for installation instructions.
- Our GitHub preview macOS packages target Apple Silicon/arm64. These releases do
  not include Intel Mac packages, and Rosetta is not supported. They use a Metal bridge around the OpenGL renderer, not a native Metal renderer.
  The legacy native backend (`platform_backend=native`) remains comparison-only diagnostic infrastructure, not a release backend.
  Qualification remains tracked in [docs/dev/macos-signoff-evidence.md](https://github.com/themuffinator/openQ4/blob/v0.14.000/docs/dev/macos-signoff-evidence.md).

## Change Log

- The optional new UI covers the gameplay HUD, weapon wheels, scopes,
  objectives, vehicle displays, multiplayer chat, scoreboards and match
  summaries. Remastered, Minimal, Competitive and Classic layout choices,
  controller button prompts and reduced-motion/flashing options are included.
- Its centered ammo, health and armor gauges match legacy sizing, spacing,
  background tones and saturation. ECG and radio displays use the installed
  legacy bitmap artwork. Cached vector drawing, reduced repeated layout work
  and cheaper fades improve performance, with immediate legacy fallback when
  a retained HUD frame cannot render. **These improvements do not yet resolve
  the new UI's performance issue; it remains disabled by default.**
- The optional interface gains animated initialization, smoother menu and
  loading transitions, campaign difficulty pages, weapon-wheel soft focus,
  scope effects and cinematic/death transitions.
- Startup avoids repeatedly hashing unchanged runtime packs. Sound decoding
  runs alongside other loading work, and unused level sounds are released.
- Audio fixes restore sound variation, stereo width, headphone settings,
  device-switch recovery, scripted fades and dialogue during time effects.
- Awakening fixes cover freeze/shatter state through saves, Retch buffs,
  missile targets, Goob/Napalm ammo feedback, speeder handling and race clocks,
  and the final battle. Campaign-specific changes stay within Awakening.
- Multiplayer improvements include bot team orders, safer navigation and
  transport handling, combat decisions, reduced network queue overhead and
  clearer team-change feedback.
- Renderer fixes improve Vulkan presentation, transparency, multisampling,
  render-target recovery, PBR lighting and reflections, and parity with
  OpenGL. Vulkan remains experimental on Linux and macOS.
- German, Brazilian Portuguese, Czech, Hungarian, Turkish and Ukrainian text
  coverage and scalable-font glyph support are expanded. The added non-retail
  languages use English voices. Console/chat input still has limitations for
  letters outside the Western European character set.
- Experimental OpenXR VR remains opt-in and requires a compatible OpenGL
  runtime. Headset hardware qualification remains outstanding; see the
  [VR guide](https://github.com/themuffinator/openQ4/blob/v0.14.000/docs/user/vr.md).
- Engine and game sources build from one checkout. Release archives retain
  exact source provenance, matching modules and verified asset checksums.

## Known Limitations

- The new UI still has measurable gameplay overhead, particularly in
  multiplayer. Broader interface, display-density and platform qualification
  remains in progress.
- Windows ARM64 remains experimental; Linux ARM64 and the preview macOS
  packages retain their preview support tiers.
- Android remains experimental within this stable release. APK signatures,
  native modules and packaged content are checked automatically, but physical
  device installation and gameplay have not yet been qualified. GLES does not
  yet provide every advanced desktop rendering effect.
- Stock multiplayer maps can report missing AAS navigation files and late
  buying-mode precaches. These remain under investigation.
