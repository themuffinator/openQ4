# openQ4 0.13.1

## Highlights

- **Saving works again in release packages.** New saves no longer fail validation because the release was incorrectly identified as build 1.
- **Release downloads are checked end to end.** Archives must decompress completely, and uploaded file sizes and SHA-256 digests must match the validated originals before a new release is published.
- **Compiled maps carry the correct geometry checksum.** A newly generated `.proc` is no longer immediately reported as out of date.

## Upgrade Notes

- Replace the complete package, keeping the engine, renderer modules, game modules, and bundled data together. Retail Quake 4 assets are still required.
- Failed save attempts in 0.13.0 did not produce a usable new save. This patch does not recover those attempts or add compatibility with unsupported older saves stamped as build 1; keep backups and use the version that wrote an older campaign save when necessary.
- Map authors: openQ4 rebuilds render geometry and collision, but does not yet include the Quake 4 AAS compiler. Rebuild navigation with the Quake 4 SDK tools after changing map geometry. The compiler now reports this limitation explicitly; remaining navigation work is tracked in [#158](https://github.com/themuffinator/openQ4/issues/158).
- macOS remains experimental on Apple Silicon/arm64, and Linux ARM64 remains a preview. The `macos_graphics_bridge=metal` package is a Metal bridge around the OpenGL renderer, not a native Metal renderer; `platform_backend=native` is comparison-only diagnostic infrastructure, not a release backend. Existing macOS visual-parity limitations remain tracked in [#98](https://github.com/themuffinator/openQ4/issues/98).

## Change Log

- Corrected release build numbering and rejected stable builds made without complete Git history, preventing freshly written saves from being mistaken for unsupported development saves ([#159](https://github.com/themuffinator/openQ4/issues/159)).
- Added full archive integrity checks and verification of the exact bytes stored by GitHub; new releases stay in draft until those checks pass ([#160](https://github.com/themuffinator/openQ4/issues/160)).
- Replaced the map compiler's placeholder checksum with the compiled map's geometry checksum, and added a clear warning when navigation cannot be rebuilt ([#158](https://github.com/themuffinator/openQ4/issues/158)).
