Interface Atlas - components

The openQ4 interface as the retained UI (ui_retained 1) draws it today, sheet by sheet, from the generators in tools/ui/ and the visual design specification, docs/dev/ui-visual-design.md. Sizes, colors, opacities and timings are the values the generated documents use; where they differ from the specification, the sheet draws the implementation and its caption says so. Parts the specification asks for that are not built yet are tagged. Hover, click or tab through any control to see its response.
