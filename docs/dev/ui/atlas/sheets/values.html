Atlas - value controls

A settings row carries its value in the value column, in marine.value: a list's value with a chevron at the row's end, the check box, the tick-track slider with its number, a fine slider's typed number, a text field, or an action's keys. The whole row is one control. The server browser's filters are the spinner squares and the cut filter tags. All of these respond to the mouse here; the spec gives each one a controller and touch mapping too.
