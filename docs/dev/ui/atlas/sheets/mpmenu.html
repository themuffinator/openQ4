Atlas - multiplayer menus

Sections 14.18 and 14.14. In a match every multiplayer menu is one card in the center screen over the live view, which the game softens; the match keeps running around it. Welcome greets a player who has just connected: the join choices, the server and its players. Escape is the in-match menu: team, players, vote, Match Control, settings, voice, server and admin. The match summary opens on the same card when a match ends, and the buy card where the server sells. Switch tabs with Q and E, the bumpers, the arrow keys or a click; Esc leaves.
