The modern way to play Quake 4

openQ4

An open-source engine and game-code replacement that runs the original retail Quake 4 on today's PCs, handhelds and Macs. This page describes openQ4 0.14.1, the latest release.

What is openQ4?

openQ4 replaces Quake 4's engine and game code with its own: an open-source engine, and game code rebuilt from the Quake 4 SDK. Your original campaign and multiplayer maps play as they always did, now with widescreen and high-refresh support, modern controls, optional visual upgrades and one install for single-player and multiplayer.

You need your own Quake 4: openQ4 does not include any Quake 4 game data. Get a legitimate copy from Steam or GOG to play.
Its own engine and game code: mods built for the original Quake 4 game DLLs won't load, and retail Quake 4 clients and servers can't play with openQ4.

Features

What you get in 0.14.1. Every visual upgrade can be switched off, and the classic interface is one setting away.

More to play

Campaigns and multiplayer

  • Two campaigns: Quake 4, or The Awakening, the recovered expansion, from Single Player → Campaign, each with its own saves. You supply the expansion files.
  • Arena Campaign (experimental): bot matches across five tiers of the stock maps, with boss matches and saved progress.
  • Better multiplayer (experimental): bots that take orders, quick and voice chat, objective markers and a server browser with favourites.
  • A demo library and player for full matches and whole campaigns, with markers and fast seeking.
  • Real liquids: swim, wade and drown in maps built for them.
Look and feel

A modern presentation

  • A new interface: rebuilt menus and settings, the Remastered HUD, weapon wheels, scopes and animated crosshairs, ready for controllers, touch, tall screens and larger text.
  • Modern lighting: soft, stable shadow maps on the higher presets, plus bloom, HDR, temporal anti-aliasing, motion blur, baked light grids, cel shading and a CRT filter.
  • Your choice of renderer: Vulkan is supported on Windows and chosen automatically, with OpenGL as the fallback. Vulkan is experimental on Linux and macOS.
  • Sound as designed: room reverb for every map, subtitles and a separate dialogue volume.
Today's hardware

Built for current systems

  • Modern displays: widescreen, ultrawide and portrait screens, multiple monitors, and smooth motion at 144 Hz and beyond.
  • Performance presets with Auto-Detect, and V-Sync, texture quality, window and fullscreen changes and most presets that apply without a restart.
  • Controllers that you can plug in at any time, and a dedicated Steam Deck setup.
  • Twelve languages, including German, Brazilian Portuguese, Czech, Hungarian, Turkish and Ukrainian.
  • Experimental extras: VR through OpenXR, an Android app, a level editor and physically based materials for mods.

Getting Started

  1. Install Quake 4

    Use a legitimate copy from Steam or GOG, and leave its q4base/ folder as it is.

  2. Download openQ4

    Get openQ4 0.14.1 for your system from the Releases page.

  3. Install it in its own folder

    Run the Windows installer, or extract the package into a folder of its own, separate from Quake 4. On Linux you can instead make the AppImage executable and run it; on a Mac, drag openQ4.app to Applications.

  4. Launch the game

    Run openQ4-client_x64.exe on Windows, the AppImage or openQ4-client_x64 on Linux, or openQ4-steamdeck on Steam Deck. openQ4 finds your Quake 4 installation by itself.

  5. Check your preset

    On first launch openQ4 picks a performance preset to suit your hardware. To change it, open Settings → Display and choose another preset, or press Auto-Detect to pick again.

Before you start

Good to know

  • Upgrading? Install the complete package into a fresh folder rather than replacing individual files. Read upgrading to 0.14.1 first: it covers your saves.
  • Portable setup: keep a copy of Quake 4's q4base/ folder next to openQ4's baseoq4/. Never copy Quake 4's .pk4 files into baseoq4/.
  • Crashes on Windows leave a log and a memory dump in the crashes/ folder beside the executable; attach both when you report one.
Manual path

If auto-detection fails

Start openQ4 with fs_basepath set to the Quake 4 folder that contains q4base/, not q4base/ itself. Getting Started has more help.

openQ4-client_x64 +set fs_basepath "C:\Program Files (x86)\Steam\steamapps\common\Quake 4"

Platforms and Requirements

Packages are built for Windows x64, Linux x64 and Steam Deck, with preview Linux ARM64, preview Apple Silicon/arm64 macOS, and experimental Windows ARM64 and Android builds.

Downloads

Packages

  • Windows x64: installer or ZIP. Windows 10 or 11 recommended.
  • Linux x64: AppImage or archive, for a modern 64-bit desktop comparable to Ubuntu 24.04 or newer.
  • Steam Deck: the Linux archive; launch openQ4-steamdeck. See the Steam Deck guide.
  • Linux ARM64 (preview): AppImage or archive. Needs full desktop OpenGL drivers, so boards with only OpenGL ES won't run it.
  • macOS (preview): unsigned OpenGL and Metal bridge archives for Apple Silicon, which macOS asks you to approve on first launch. Players have run them only on current macOS.
  • macOS, signed: signed and notarized builds for Apple Silicon and Intel Macs from Mac Source Ports.
  • Windows ARM64 (experimental): installer or ZIP, not yet confirmed on real hardware.
  • Android (experimental): an ARM64 APK for Android 7.0 or newer with OpenGL ES 3.0. See Android setup.
Hardware

Minimum and recommended

  • CPU: 64-bit dual-core minimum; a modern quad-core recommended.
  • Memory: 4 GB minimum; 8 GB recommended, or 16 GB for high presets and resolutions.
  • Graphics: working OpenGL drivers with about 1 GB of video memory at minimum; OpenGL 4.1 or Vulkan graphics with 2 GB or more recommended, or 6 GB or more for the Quality preset and above.
  • Storage: about 12 GB including Quake 4; 15 GB or more recommended.

Compatibility

What works

Your original game

  • openQ4 runs the official retail Quake 4 assets with its own engine and game code.
  • It checks at start-up that your Quake 4 files are the official ones.
  • Single-player and multiplayer share one install, and The Awakening keeps its own saves and settings.
  • Widescreen, ultrawide and multi-monitor setups are handled automatically, with the field of view and weapon framing to match.
What doesn't

Known boundaries

  • Mods built for the original proprietary Quake 4 game DLLs won't load.
  • Retail Quake 4 clients and servers can't join openQ4 games, or the other way round. Play online with matching openQ4 versions.
  • openQ4 is in beta, and compatibility work is ongoing.

See release status for corrections made since 0.14.1 shipped, and the 0.14.1 release notes for everything new. Development continues toward 1.0 on the roadmap.
